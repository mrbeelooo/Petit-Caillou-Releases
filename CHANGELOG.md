# Changelog

## 1.0.2 — 2026-11-16
- T.O.S now also works while the host transport is stopped (for example when playing live): the LFO waits at its start position until the first sound, instead of running freely.

## 1.0.1 — 2026-11-05
- A complete redesign of the look, built with Blender: the three skins (Raw Alu, Warm Red and Cold Blue) are now richer, more realistic 3D renders.

## 1.0.0 — Initial release
- First public release of PetitCaillou: four-stage phaser, VST3 for Windows, AU and VST3 for macOS.
